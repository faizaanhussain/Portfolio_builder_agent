Hosting & Deployment

1. Vercel (1-Click Deployment)

Run npx vercel generated_sites/<your_dir> or upload the unzipped folder at vercel.com/new.

2. GitHub Pages

Push your generated folder to a GitHub repository and turn on GitHub Pages in repository settings.

3. Local Preview Server

Run python preview_server.py --dir generated_sites/<your_dir> to re-host locally anytime.
